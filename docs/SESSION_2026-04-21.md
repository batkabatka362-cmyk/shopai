## 6. What the 24/7 daemon does today

`python scripts/run_daemon.py` starts a loop that:

1. Discovers winners (ManualSeedSource + peer observers)
2. For each winner up to `max_launches`:
   - Generates ad copy (ContentGenerator)
   - Creates product on Shopify with A3 JSON-LD metafield
   - Optionally generates fal.ai videos (cache-checked first; opt-in)
   - Runs EU AI Act gate if any EU target (A1)
   - Launches Meta Ads campaign PAUSED (D2 verifier on every write)
3. CampaignActivator flips PAUSED → ACTIVE with:
   - Crisis check, tripwire, simulator, readiness, constraints
   - Moby vote comparison (A7) — rationale ledger gate entry
   - Engine outcome bus emission
4. Every 5 cycles:
   - Learner distill pass
   - **llms.txt + markdown mirror rebuild** (this session)
5. Order webhook fires → agentic attribution (A4) + OutcomeRecorder
   → Moby resolve-on-outcome → engine outcome bus

All of the above ran pre-session ONLY partially (A1-A3
in-tree but not wired; A4-A7 didn't exist). Every step that
touches live money now has an opt-in gate + verify step.
